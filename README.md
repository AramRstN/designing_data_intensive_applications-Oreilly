# Designing Data-Intensive Applications — Structured Notebook Summaries

This repository contains a **comprehensive, chapter-by-chapter breakdown** of *Designing Data-Intensive Applications (2nd Edition)* by Martin Kleppmann and Chris Riccomini.

---

## Covered Topics in Each Chapter:

- Trade-Offs in Data Systems Architecture
- Defining Nonfunctional Requirements
- Data Models and Query Languages
- Storage and Retrieval
- Encoding and Evolution
- Replication
- Sharding
- Transactions
- The Trouble with Distributed Systems
- Consistency and Consensus
- Batch Processing
- Stream Processing
- A Philosophy of Streaming Systems
- Doing the Right Thing
